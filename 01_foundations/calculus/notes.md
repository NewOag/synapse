# 微积分基础

微积分在机器学习中的核心作用是**描述函数如何随输入变化**，进而指导参数朝损失减小的方向移动。

---

## 导数

导数 f'(x) 描述函数在点 x 处的瞬时变化率：

```
        f(x+h) - f(x)
f'(x) = ─────────────   (h → 0)
               h
```

几何意义：函数曲线在该点的切线斜率。

---

## 偏导数与梯度

对多元函数 f(x₁, x₂, ..., xₙ)，偏导数固定其余变量只对 xᵢ 求导：

```
∂f        f(..., xᵢ+h, ...) - f(..., xᵢ-h, ...)
──── ≈   ─────────────────────────────────────────   (h → 0)
∂xᵢ                        2h
```

梯度是所有偏导数组成的向量，指向函数值**增长最快**的方向：

```
∇f = (∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ)
```

---

## 链式法则

复合函数求导，逐层相乘，是反向传播的数学基础：

```
d/dx f(g(x)) = f'(g(x)) · g'(x)
```

---

## 激活函数

激活函数引入非线性，使神经网络能拟合复杂函数。

### Sigmoid

```
              1
σ(x) = ───────────────
         1 + e^(-x)
```

导数推导：

```
σ'(x) = σ(x) · (1 - σ(x))
```

性质：
- 输出范围 (0, 1)，可解释为概率
- 对称性：σ(-x) = 1 - σ(x)
- 两端梯度趋近于 0 → 梯度消失问题的根源

### ReLU

```
ReLU(x) = max(0, x)

           ⎧ 1   x > 0
ReLU'(x) = ⎨
           ⎩ 0   x ≤ 0
```

性质：
- 正数域梯度恒为 1，缓解梯度消失
- 负数域输出为 0（神经元"死亡"问题）
- 计算极简，深层网络的默认选择

### Tanh

```
         e^x - e^(-x)
tanh(x) = ────────────
         e^x + e^(-x)

tanh'(x) = 1 - tanh²(x)
```

性质：
- 输出范围 (-1, 1)，以 0 为中心，比 sigmoid 收敛更快
- tanh(0) = 0，tanh'(0) = 1

## 数值微分

当解析导数难以推导，或需要验证手推梯度时，用数值方法近似。

### 中心差分法

比前向差分精度高一阶（误差 O(h²)）：

```
         f(x+h) - f(x-h)
f'(x) ≈  ────────────────
                2h
```

取 h = 1e-5 时，误差约在 1e-10 量级。

**用途**：梯度检验 — 验证手写反向传播的梯度是否正确。

---

## 梯度下降

沿梯度反方向更新参数，使损失函数不断减小：

```
x ← x - η · ∇f(x)
```

η 是学习率，控制每步移动幅度。

收敛分析（以 f(x,y) = x² + y² 为例）：

```
∇f = (2x, 2y)
更新：x ← x·(1 - 2η)
收敛条件：|1 - 2η| < 1，即 η < 1
η = 0.1 时每步缩小 80%，50 步后误差约 1e-9
```

---

## 实现要点

**数值稳定性**
- h 取 `1e-5`：太大近似误差大，太小浮点精度损失
- Sigmoid 对极大输入标准库已处理溢出，无需额外保护

**代码结构**
- 计算逻辑在 `src/lib.rs`，pub 导出供测试和其他 crate 引用
- `src/main.rs` 仅做演示
- 测试分三层：数值正确性 / 数学性质 / 数值稳定性

**关键函数**

| 概念 | 函数 | 位置 |

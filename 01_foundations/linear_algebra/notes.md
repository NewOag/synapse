# 线性代数基础

线性代数是机器学习的语言——数据是向量，模型是矩阵变换，训练是在高维空间里移动。

---

## 向量

向量是有序的数值列表，表示空间中的一个点或方向。

### 基本运算

```
加法：  a + b = [a₁+b₁, a₂+b₂, ..., aₙ+bₙ]
数乘：  s·a   = [s·a₁, s·a₂, ..., s·aₙ]
```

### 点积

```
a · b = a₁b₁ + a₂b₂ + ... + aₙbₙ = Σ aᵢbᵢ
```

几何意义：`a · b = ‖a‖ ‖b‖ cos(θ)`，θ 为两向量夹角。
- 点积为 0 → 两向量正交（垂直）
- 点积为正 → 夹角小于 90°，方向相近

### 范数（向量长度）

```
L2 范数（欧几里得距离）：‖a‖₂ = sqrt(a₁² + a₂² + ... + aₙ²)
L1 范数（曼哈顿距离）：  ‖a‖₁ = |a₁| + |a₂| + ... + |aₙ|
```

L2 常用于正则化，L1 产生稀疏解（部分权重归零）。

### 外积

```
u ⊗ v = 列向量 u 乘以行向量 vᵀ，结果是矩阵

u = [u₁, u₂]ᵀ，v = [v₁, v₂, v₃]

        ┌ u₁v₁  u₁v₂  u₁v₃ ┐
u ⊗ v = │ u₂v₁  u₂v₂  u₂v₃ │
        └                   ┘
```

外积在反向传播中出现：全连接层的权重梯度 = 误差向量 ⊗ 输入向量。

## 矩阵

矩阵是二维数组，表示线性变换——将一个向量空间映射到另一个。

### 矩阵乘法

```
C = A · B，其中 A 是 (m×k)，B 是 (k×n)，C 是 (m×n)

C[i][j] = Σₚ A[i][p] · B[p][j]
```

理解：C 的第 (i,j) 个元素 = A 的第 i 行与 B 的第 j 列的点积。

性质：
- 不满足交换律：AB ≠ BA（一般情况）
- 满足结合律：(AB)C = A(BC)
- A · I = A（I 为单位矩阵）

### 转置

```
(Aᵀ)[i][j] = A[j][i]

A = [[1, 2, 3],      Aᵀ = [[1, 4],
     [4, 5, 6]]            [2, 5],
                           [3, 6]]
```

性质：
- (Aᵀ)ᵀ = A
- (AB)ᵀ = BᵀAᵀ（顺序反转）

### 矩阵向量乘法

```
y = A · x，其中 A 是 (m×n)，x 是 (n,)，y 是 (m,)

y[i] = Σⱼ A[i][j] · x[j]
```

这是神经网络前向传播的核心操作：线性层 = Wx + b。

### 单位矩阵

```
I₃ = [[1, 0, 0],
      [0, 1, 0],
      [0, 0, 1]]
```

对角线为 1，其余为 0。任何矩阵乘单位矩阵等于自身：A · I = I · A = A。

### Frobenius 范数

矩阵的"长度"，所有元素平方和开根：

```
‖A‖_F = sqrt( Σᵢⱼ A[i][j]² )
```

用于衡量矩阵大小，权重正则化时出现。

## 存储方式

实现采用**行优先（row-major）**一维数组：

```
M = [[1, 2, 3],       data = [1, 2, 3, 4, 5, 6]
     [4, 5, 6]]

M[i][j] = data[i * cols + j]
```

行优先对行访问友好（缓存局部性好），与 C/NumPy 默认一致。

## Backend 抽象

为支持未来切换 SIMD 或 GPU 后端，基础运算通过 `Backend` trait 隔离：

```
trait Backend {
    vadd(a, b, out)          // 向量加法
    vsub(a, b, out)          // 向量减法
    vscale(v, s, out)        // 标量乘
    dot(a, b) -> f64         // 点积
    matmul(a, b, out, m,k,n) // 矩阵乘法
}
```

当前实现：`CpuBackend`（纯标量循环）。
切换后端只需实现新 struct，调用方不改动。

## 实现要点

**数值稳定性**
- 矩阵乘法用 i-p-j 循环顺序（而非 i-j-k），对缓存更友好
- 维度不匹配时 `assert!` 提前报错，避免越界后的静默错误
